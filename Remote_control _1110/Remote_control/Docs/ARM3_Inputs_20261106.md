# ARM3遥控输入候选

在原项目上增加remote_arm3.c/h并接入app_main；现有双语OLED及v1车辆帧布局保留。K10长按切ARM页，须先收到8A/version2/capabilities bit1。F签发会话，挑战应答，新采样10ms，事件序号只对新意图递增；重复事件不再执行。

ARM键位：K10短申请/双释放；K11左/右/双；K9 J1–6；K1/K2档位加减；K3/K4按住正负点动；K12短选四预设、长执行、双灯；K6选侧停；K5全局停，长按不授权车辆；K7/K8保留页面/语言。双臂选择禁止点动。改变侧/轴/档/方向先停并等待松开。ARM期间每100ms发原v1中性帧；K5物理上升沿另保留原停车帧并固定同一事件序号重试。

状态8B显示owner/permit/state/原因，8C显示选中关节实际角度、真实反馈年龄和operation。断链超过300ms后握手，须全松开后主动申请；后端租约和许可分别计时。

验证：Tests/run_remote_tests.ps1包含新增ARM能力/HELLO/点动/ALIVE/松开/断链及原OLED、真实NRF、按键、双语、app和跨编码测试。真实Keil全量重构建0错误0警告，Code47856、RO8312、RW168、ZI8880。没有烧录或实物按键、无线链路及机械臂动作验收。
