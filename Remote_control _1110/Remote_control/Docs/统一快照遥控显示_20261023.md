# 统一快照遥控显示适配

本轮保持原九页、控制按键、授权、RX/LOST、历史有效值及告警显示，新增可选0x8A元数据（版本1、采集序号、采集时间、活动仲裁源）。首页每秒交替原模式和SRC，概览交替原COM AGE和SNAP；0x81遥控持权位仍仅表示遥控授权，不能把CAN/HMI持权显示成遥控持权。

0x81～0x89旧帧和CRC不变；0x8A只标记它自身采集周期，不代表九类旧帧同一个seq。元数据接收年龄不等于每个样本年龄。稀疏ACK下诊断/同步可能数秒才到，继续诚实显示OLD/LOST，未完成全部100ms实时验收。
