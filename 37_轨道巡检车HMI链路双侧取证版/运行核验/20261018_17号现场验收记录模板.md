## 二、通信保真

- [ ] 上电后屏端未自动授权、未恢复旧目标。
- [ ] 连续只读运行10分钟，保存屏端视频和F4 `hmi status` 两次以上。
- [ ] P0～P8逐页往返至少三轮，旧页面数据持续更新。
- [ ] 元数据0200H、基础区0000H、辅助区0050H/0070H/0090H/00B0H、控制状态0460H均有合法请求和回复。
- [ ] 屏端P2合法接收计数增长，不能只依据F4发送计数判断通过。
- [ ] 双向原始抓包采用同一时间基准，保存为JSONL。

抓包文件：`待填写`

## 三、授权与低速运行

- [ ] 空闲时按一次授权，只有一笔申请，主控确认`owner=HMI`和新`session`。
- [ ] 授权确认后的第一笔共同目标为`0rpm`，且在100ms内出现。
- [ ] 不触摸滑块保持30秒，0rpm目标持续刷新，未发生自动释放。
- [ ] 架空或可靠隔离条件下测试`+50rpm`、`-50rpm`、`+100rpm`、`-100rpm`。
- [ ] 共同目标、逐轴执行输出、逐轴实际反馈分开记录。
- [ ] 换向先回到真实零速，再允许反向目标。

## 四、释放、急停和重复急停

- [ ] 正常取消按0.4m/s²受控减速，停稳后释放控制权。
- [ ] 运行中第一次急停按0.5m/s²受控减速，停车事件成功确认。
- [ ] 停车成功后重复急停1次、5次、20次，事件号不新增，停车写事务不重复增加。
- [ ] 重复急停后只按一次授权，重新获得新session，首目标仍为0rpm。
- [ ] 恢复授权后滑块重新有效，可再次低速运行。
- [ ] 停车确认后返回主页成功。

## 五、异常和互斥

- [ ] 真实停车未确认时，重复急停不能绕过锁定。
- [ ] 屏端失联触发主控目标/会话超时，受控停车并释放控制权。
- [ ] 屏端复位后只恢复只读，不自动授权、不恢复非零目标。
- [ ] F4复位后boot变化，屏端清理旧会话和旧目标。
- [ ] 遥控器先占用时，屏端申请被拒绝且不产生运动写。
- [ ] 屏端占用时，无关遥控器离线不撤销HMI控制权。
