# HMI运动控制R2实施与验证记录

日期：2026-10-15

## 1. 实施范围

本次在底盘主控工程中落地HMI13-R2共同目标转速控制，不修改08号屏工程和`.pix`文件，不开放CAN运动控制。

- HMI与遥控均提交一个共同目标rpm；左轴、右轴或双轴由`APP_SERVO_CONTROL_AXIS`编译配置决定。
- R2使用0100H起24字完整邮箱、0021H共同rpm、axis固定0、字典修订2；R1运动写入拒绝，原03H只读保留。
- 实现先到先得仲裁、授权准备、目标/会话双期限、异步写完成跟踪、换向过零、双轴独立P同步和统一受控停车。
- 释放/返回主页使用400mm/s²，失联和超时使用400mm/s²，软件急停使用500mm/s²；停车成功要求新鲜零速样本和有效使能反馈，随后释放owner。
- HMI、遥控和CLI共享停止仲裁槽；无关接口掉线不影响当前owner，跨源急停只请求当前owner停车，不把控制权授予请求方。
- 统一运行限速为-1600～1600rpm；CAN运动开关保持关闭。

## 2. 主要变更文件

- `APP/HMI/app_control_arbiter.c/.h`：控制权、停车事件、代次和停止请求。
- `APP/HMI/app_hmi_control.c/.h`：R2邮箱、授权、共同斜坡、同步、写完成和停车状态机。
- `APP/HMI/app_hmi_snapshot.c`、`APP/HMI/app_hmi_state.c/.h`：0460H～049FH新状态块和原子快照发布。
- `APP/HMI/app_hmi.c`：保留UART5收发边界，增加只读CLI诊断，移除跨源错误撤权路径。
- `APP/app_remote_servo.c/.h`：HMI占用隔离、跨源K5停车代理、准备阶段取消收尾。
- `APP/app_cli_servo_session.c/.h`：速度模式外部急停停车；位置/脉冲模式沿用原停止路径。
- `Device/aimtor_servo.c`：HMI控制掩码、停车写权限、使能/状态轮询和速度事务序号。
- `APP/app_config.h`：1600rpm、R2字典、时效和停车参数。

### Keil静态构建

`Tests/build_hmi_control.ps1`支持三轴、待机、HMI控制开关和只读配置，并检查Flash边界和静态调用图栈余量。已获得的构建日志中，已完成配置报告`0 Error(s), 0 Warning(s)`；代表性结果如下：

- Flash结束地址约`0x08036434`，低于身份区`0x080E0000`。
- `servo_comm_task`静态调用图余量约680字节。
- `hmi_task`静态调用图余量约1480字节。
- `cli_task`静态调用图余量约584字节。
- 静态调用图不能替代运行期高水位测量。

最终全矩阵构建过程中曾因临时Keil进程占用构建目录而中断，临时工程和RTE自动文件已恢复；因此不能把该次中断称为15配置全部完成。重新执行时应确保没有同一脚本的并行Keil实例，并将产物目录作为正式交付物保存。

## 4. 回归限制

- 默认完整回归仍被既有`Tests/test_position_monitor.c`中的机械换算硬编码断言阻断：测试期望10000计数对应约581.1946mm，而当前工程机械减速比为8/3，对应值约217.948mm。该断言未删除、未用修改生产逻辑掩盖。
- 将位置监控组显式隔离后，其余回归继续执行；在后续正式回归前，应由项目负责人确认该测试期望是否应按当前机械参数更新。

## 6. 联调入口

屏端应按《车载屏13号工程_伺服运动控制接口与开发需求_20261015.md》发送R2，不读取或改写0100H邮箱作为反馈来源；控制反馈读取0460H起64字状态块，命令结果读取0120H起20字结果区。主控CLI可使用`hmi status`查看owner、代次、会话、目标、输出、同步和停车事件。

完成实屏和实物验收前，不能宣称13号屏已经可以安全驱动车辆；当前交付是主控软件实现和可复现的主机/静态验证基线。
