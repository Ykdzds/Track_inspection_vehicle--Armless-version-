# AM26C31 电路设计说明(最终方案)

> 依据:TI AM26C31 数据手册(ZHCSVF3P,2024 年 3 月修订,英文原版 SLLS103)
> 版本:最终方案 —— 两组使能端均由 STM32 独立直控,PC8/PC9 各带默认态电阻
> 本版修正:原版本误认为两组使能均为"高电平有效、均由 PC8 控制",与数据手册不符,已全部更正。

## 一、方案结论

- `PC8` 直连 4脚 `G`(高电平有效使能,控制第 1、2 路),配 10kΩ 下拉到 GND,默认低 = 禁止;
- `PC9` 直连 12脚 `Ḡ`(低电平有效使能,控制第 3、4 路),配 10kΩ 上拉到 3.3V,默认高 = 禁止;
- **使能全部四路**:`PC8=1` 且 `PC9=0`;
- **禁止全部四路**:`PC8=0` 且 `PC9=1`(即上电/复位/下载固件期间的默认状态);
- 两脚独立控制,左、右伺服使能可分别开关;
- 不设反相器、不设与门;硬件安全与门见第七节,作为可选升级项;
- `PC9` 重新纳入资源分配,承担 12脚控制。

```text
STM32                     AM26C31(16脚封装)
PC8 ────────────────→  4脚  G     (高电平使能1、2路)
                        │
                        └─ 10kΩ 下拉 → GND

PC9 ────────────────→  12脚 Ḡ    (低电平使能3、4路)
                        │
                        └─ 10kΩ 上拉 → +3.3V
```

## 二、数据手册关键信息

### 2.1 引脚功能(表 4-1)

| 引脚(16脚) | 名称 | 极性 | 控制通道 |
|---|---|---|---|
| 4 | G | Active high enable(高电平有效) | 第 1、2 路 |
| 12 | Ḡ | Active low enable(低电平有效) | 第 3、4 路 |
| 8 | GND | — | 地 |
| 16 | VCC | — | 电源(4.5～5.5V,标称 5V) |

其余:1A/2A/3A/4A 为四路输入,1Y/1Z～4Y/4Z 为四路差分输出。

### 2.2 功能真值表(表 7-1,每路驱动器)

| 输入 A | G(4脚) | Ḡ(12脚) | 输出 Y / Z |
|---|---|---|---|
| H | **H** | X | H / L(正常输出) |
| L | **H** | X | L / H(正常输出) |
| H | X | **L** | H / L(正常输出) |
| L | X | **L** | L / H(正常输出) |
| X | **L** | **H** | Z / Z(**高阻,禁止**) |

手册 7.3.1 节原文:"A logic high on the G pin or a logic low on the Ḡ pin enables the device to operate."

### 2.3 输入门限(5.3 节)

- VIH(min)= **2V**,VIL(max)= **0.8V** → STM32 的 3.3V GPIO 可直接驱动,无需电平转换;
- 输入电流仅 ±1µA,芯片内部**无上/下拉** → 使能脚任何时候不得悬空;
- 禁止态输出为高阻(三态),使能/禁止切换时间 tPZH/tPZL 典型约 10ns。

## 三、默认态电阻的作用与选值

### 3.1 为什么必须加

STM32 上电、复位、下载固件、看门狗复位期间,GPIO 均为**高阻浮空**。此时使能脚电平完全由外部电阻决定:

| 引脚 | 电阻 | 浮空期电平 | 对照门限 | 结果 |
|---|---|---|---|---|
| 4脚 G | 10kΩ 下拉 GND | ≈0V | < 0.8V | 1、2路禁止 ✓ |
| 12脚 Ḡ | 10kΩ 上拉 3.3V | 3.3V | > 2V | 3、4路禁止 ✓ |

AM26C31 混合极性的设计使两个安全默认态**恰好都是禁止态**,无需任何额外逻辑即可满足"上电、复位、跑飞时默认禁止输出"。

### 3.2 电阻不影响正常使能

GPIO 推挽输出内阻仅几十欧,远强于 10kΩ:

- PC8 输出高:4脚稳定在 3.3V,下拉仅分走 0.33mA,电平不降,仍满足 VIH;
- PC9 输出低:12脚稳定在 0V,上拉电流被 GPIO 吸收,仍满足 VIL。

电阻只在 GPIO 浮空期间起作用,正常运行时对使能功能零影响。

### 3.3 上拉接 3.3V 的注意事项

- 接 3.3V 而非 5V:复位期间 MCU 脚高阻,若上拉到 5V 会把非 5V 容忍(非 FT)引脚抬到 5V;接 3.3V 已满足 VIH ≥ 2V;
- 上电时序窗口:若 3.3V 由 5V 经 LDO 产生,5V 先建立时 12脚会被上拉电阻短暂拉向 0V,3、4路理论上有一极短"使能"窗口。此时 MCU 未上电、3A/4A 浮空、伺服未 Servo ON,风险很小,工程上可接受;
- 如需消除该窗口:12脚上拉改接 5V,前提是 PC9 为 FT(5V 容忍)引脚,需查所用 STM32 型号;
- 4脚下拉接 GND 不受任何电源轨影响,从 t=0 起即可靠禁止。

## 四、四路通道分配

| AM26C31 通道 | 输入(ST 单端) | 差分输出 | 连接对象 |
|---|---|---|---|
| 通道 1 | 左 PUL | 1Y / 1Z | 左驱动器 PUL+ / PUL− |
| 通道 2 | 左 DIR | 2Y / 2Z | 左驱动器 DIR+ / DIR− |
| 通道 3 | 右 PUL | 3Y / 3Z | 右驱动器 PUL+ / PUL− |
| 通道 4 | 右 DIR | 4Y / 4Z | 右驱动器 DIR+ / DIR− |

STM32 侧引脚:

| STM32 引脚 | 功能 |
|---|---|
| PE5 / TIM9_CH1 | 左伺服 PUL |
| PB0 | 左伺服 DIR |
| PB9 / TIM11_CH1 | 右伺服 PUL |
| PB1 | 右伺服 DIR |
| PC8 | 4脚 G —— 1、2路使能(高有效) |
| PC9 | 12脚 Ḡ —— 3、4路使能(低有效) |

建议每个 STM32 输出到 AM26C31 输入之间串联 100～330Ω 电阻,抑制边沿振铃和 EMI,阻值结合 PCB 走线长度和实测波形确定。

数据输入 1A～4A 复位期间虽然浮空,但因两使能端默认禁止、输出呈高阻,不会向外发送脉冲,无需为数据输入加下拉。

## 五、软件控制

### 5.1 初始化(进 main 第一件事)

```c
// 立即写禁止态,与外部电阻形成双保险
HAL_GPIO_WritePin(GPIOC, GPIO_PIN_8, GPIO_PIN_RESET);  // 4脚 = 低  → 禁止1、2路
HAL_GPIO_WritePin(GPIOC, GPIO_PIN_9, GPIO_PIN_SET);    // 12脚 = 高 → 禁止3、4路

// 配置 PC8、PC9 为推挽输出(低速/中速均可)

// ...初始化 TIM10、TIM11、USART2/RS485、安全状态...
```

建议封装统一接口,避免散落各处写反极性:

```c
#define AM26C31_ENABLE_12()   HAL_GPIO_WritePin(GPIOC, GPIO_PIN_8, GPIO_PIN_SET)
#define AM26C31_DISABLE_12()  HAL_GPIO_WritePin(GPIOC, GPIO_PIN_8, GPIO_PIN_RESET)
#define AM26C31_ENABLE_34()   HAL_GPIO_WritePin(GPIOC, GPIO_PIN_9, GPIO_PIN_RESET)
#define AM26C31_DISABLE_34()  HAL_GPIO_WritePin(GPIOC, GPIO_PIN_9, GPIO_PIN_SET)

#define AM26C31_ENABLE_ALL()  do { AM26C31_ENABLE_12();  AM26C31_ENABLE_34();  } while (0)
#define AM26C31_DISABLE_ALL() do { AM26C31_DISABLE_12(); AM26C31_DISABLE_34(); } while (0)
```

### 5.2 启动顺序

```text
PC8=0、PC9=1(禁止态)
→ 初始化 TIM10、TIM11
→ 初始化 USART2 和 RS485
→ 读取安全状态与接触器反馈
→ 确认两台伺服无故障
→ 通过 Modbus 执行 Servo ON
→ 等待抱闸释放、驱动器稳定
→ PC8=1、PC9=0
→ 开始输出 PUL/DIR
```

### 5.3 立即禁止的条件(任一成立即拉回禁止态)

- 安全链状态无效;
- RS485 通信超时;
- 任一伺服报警;
- 接触器反馈异常;
- 电池电压过低;
- 检测到脉冲参数异常;
- 其他系统发出停车请求。

```c
AM26C31_DISABLE_ALL();   // PC8=0 且 PC9=1 → 四路高阻
```

## 六、电源与去耦

```text
12V 控制电池 → 5V DC/DC → AM26C31 VCC
```

- VCC 旁就近放置 0.1µF 陶瓷去耦电容,建议再并 1～4.7µF 局部储能电容;
- 去耦电容紧靠 VCC(16脚)与 GND(8脚);
- 差分输出线成对、等长、并行布线,远离 51.2V 动力线和接触器线圈;
- 连接伺服用屏蔽双绞线;
- 控制地与动力地按 RS485 及伺服驱动器接口要求统一规划。

## 七、安全定位与边界

### 7.1 三层安全结构

```text
第一层:硬件安全链切断伺服动力(安全继电器 → 51.2V 接触器 / STO)
第二层:AM26C31 使能禁止(本方案的软件门控)
第三层:STM32 停止定时器与指令
```

### 7.2 本方案的边界

- 默认态电阻 + 软件能保证:**复位、上电、下载固件、看门狗复位、正常停车**时四路输出高阻;
- **防不住**:程序跑飞但 GPIO 仍保持输出、停留在使能态——此时软件无法自动拉回。因此**急停必须依赖第一层硬件安全链**,不能只靠 AM26C31 使能;
- AM26C31 输出禁止只能阻止新的脉冲指令,不能替代动力接触器、安全继电器、驱动器 STO、伺服故障处理、电机抱闸。

### 7.3 可选升级:硬件安全与门

若后续要求"急停时即使 STM32 完全失控也能硬件强制切断差分输出",在 PC8/PC9 与使能脚之间串入与门(如 74AHCT08),并注意 12脚极性:

```text
与门输出 = PC8 AND SAFE_PULSE_EN     → 4脚 G
反相(与门输出经反相器)               → 12脚 Ḡ(低有效)
```

即:与门输出直送 4脚;与门输出经一反相器送 12脚。当前最终方案**不包含**此电路,升级时需重新评审默认态电阻位置。

## 八、与原版本的差异

| 项目 | 原版本(已作废) | 最终方案 |
|---|---|---|
| 4脚 G | 误认为高有效,PC8 直控 | **正确**——高有效,PC8 直控 + 10k 下拉 |
| 12脚 Ḡ | 误认为高有效,PC8 直控 | **更正**——低有效,PC9 直控 + 10k 上拉 3.3V |
| PC9 | 不使用 | 重新启用,控制 12脚 |
| 74AHCT08 与门 | 作为正式方案 | 降级为可选升级项,当前不设 |
| 上电默认 | 靠 PC8 下拉 | 4脚下拉 + 12脚上拉,双端硬件默认禁止 |

> 若按原版本接线(PC8 同时直连 4脚与 12脚),PC8=1 时 12脚也为高 → 3、4路永远禁止,右伺服无法输出任何脉冲。
