# 双轴同步方案 V1.3 修改对照

原件：`轨道巡检车前后驱动轴动态同步与在线S型速度规划最终方案_V1.0_20261021.md`，正文版本 V1.2。原件保留。

新版：`轨道巡检车前后驱动轴动态同步与在线S型速度规划最终方案_V1.3_20261030.md`。本对照与新版均为独立文件。

| 原位置/认识 | V1.3 修订 | 对应实施 |
|---|---|---|
| 一、十六：优先等效滚动线速度 | 轮轴转速同步为主，方向/传动比归一化，轮径作监视与机械校核 | 新模块内部 rad/s，命令和反馈逐轴换算 |
| 二、八：前后/左右模型容易混淆 | 1435 mm 是轨距，不代入前后差速公式；曲线能力独立校核 | 不注入横摆差速 |
| 三、十九、二十三：旧参数 | 更新正常 0.15/0.30、分级停车 0.50/0.60/0.80，区分源码/读回/实测 | 现有停车参数不改 |
| 四、十五、二十三：CAN 先补偿后斜坡 | 撤销过时判断；基线 CAN 已经先斜坡后补偿 | 正常输出再统一到共同分配器 |
| 七及参数段：驱动器正常斜坡认识 | H06_05 正常 1 ms 保护；CLI 另有直接速度斜坡；H06_06 约 4541 ms | 不改驱动寄存器配置策略 |
| 五、十七：结构建议尚未实施 | 纯 C 协调器接入遥控双轴、HMI、CAN，无新增任务 | 新 .c/.h 列入原 uvprojx |
| 随机目标时间语义缺少复现 | 更新目标结算旧轨迹，不重置服务时间 | 删除目标变更 boundary；连续 retarget |
| 十七、二十三：批次可能绑定积分 | 批次锁存与健康服务时间分别管理 | 等 ACK 仍推进轨迹；保留既有保护 |
| 同步 `active/pair_valid` 含义混杂 | 新配对事件、反馈有效、补偿有效分离 | 原样本年龄失效，重复调用不重复积分 |
| 十七：时间对齐原则 | 有界历史插值，无依据仅原始配对 P；记录来源 | ≤40 ms 跨度，<100 ms 年龄；拒绝乱序 |
| 十七：联合约束未具体落地 | 固定次数解析区间分配，差动优先，共同参考受限 | 轴限速、方向、加减速度、S 跃度约束 |
| 十八：S 选择尚不明确 | 纯 C 速度模式三段解析 OTG，从当前速度/加速度重规划 | S 默认关闭；jerk=0 不允许启用 |
| 十八：突变目标处理 | 允许收回当前加速度所需最小超调，记录界和时间 | 零/换向/硬限速优先、舒适 S 可退出 |
| 十九：普通归零与安全停车边界 | 普通零和换向减速纳入主动同步；K5/失联/快停保留原执行器 | 禁止越零、增幅和唤醒停轴，保留真实零确认 |
| 十七：PI 抗饱和 | 仅新对齐配对积分，最终量化差动回算，底层改写重锚 | PI 默认关闭；Ki/Kaw 无隐含默认正值 |
| 二十：仅 360 kg | 增加 250/360 kg 平动惯性对照及额外阻力/热/黏着要求 | 不据理想转矩表放行实车 |
| 测试、诊断、交付散在多章 | 合并为单一验证、放行及回退章节 | 864 组延迟样本、随机 OTG、动态模型 CSV |
| 历史 Kp 数据可被过度解释 | 明确轨迹不等、稳态未全面改善、时间与固件信息不全 | 不提高 Kp，不宣称已实物改善 |
| 交付状态曾写只读分析 | 改为软件候选版已实现，S/PI 关闭，硬件各项未验证 | 以最终交付报告日志/哈希为准 |

源码主要改动：`APP/app_dual_axis_motion.c/.h`、`app_remote_servo_sync.c/.h`、三来源适配、`app_normal_ramp.h`、`app_config.h`、`app_debug_cli.c`、LCD 栈预算及原 Keil 工程文件。主机脚本增加新编译单元；原安全断言保留。两处测试预期按新规则调整：CAN 末端一次舍入，机械差异及同步优先下允许较长共同到速；服务积分和轴最终变化率仍单独约束。

验收区分：命令时序、算法模型、真实轮轴动态同步、负载/停车安全。缺少实物数据的后两者保持未验证。具体测试通过与固件哈希见交付报告。
