# 底盘统一加减速设计说明

> 2026-10-13按键迁移：物理K5短按受控停车、长按授权；K6短按看门狗测试（默认关闭）；K7/K8短按上一页/下一页。K1～K4无功能但三类事件仍上传。两端固件必须配套升级，升级期间禁止运行；协议无版本协商，旧新混用会功能错位。内部K1枚举/接口及旧文件名仅为兼容保留，实际由K5触发。

日期：2026-10-12

## 1. 适用范围

遥控器、HMI 和 CAN 的 RS485 速度模式共用物理加减速斜坡。CLI 位置模式、外部脉冲模式和看门狗独立恢复策略不纳入本次统一斜坡。

## 2. 第一版调试参数

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `APP_DESIGN_ACCELERATION_MPS2` | `0.15 m/s²` | 正常目标速度增加 |
| `APP_DESIGN_DECELERATION_MPS2` | `0.30 m/s²` | 正常目标速度降低、CAN正常停车 |
| `APP_REMOTE_SERVO_LINK_STOP_DECEL_MPS2` | `0.40 m/s²` | 遥控器失联停车 |
| `APP_REMOTE_SERVO_K5_STOP_DECEL_MPS2` | `0.50 m/s²` | 遥控器K5受控停车 |
| `APP_REMOTE_SERVO_MAX_RPM` | `1529 rpm` | 遥控器电机轴运行上限 |

当前轮径为 `185 mm`，机械链路为 `3:1`减速机、`18`齿大链轮和`16`齿小链轮。总传动比为 `8/3≈2.6667`（电机转速/车轮转速）。速度换算使用：

```text
rpm/s = a × 60 × 减速比 / (π × 轮径)
```

因此当前实际配置下正常加速约 `41.29 rpm/s`，正常减速约 `82.59 rpm/s`。20 km/h对应电机约 `1529 rpm`，1529 rpm约为 `19.99 km/h`，是20 km/h硬限速向下取整后的运行上限。`1750 rpm`仅为电机绝对保护上限，不能作为车辆运行指令。

## 3. 共享斜坡实现

`APP/app_motion_ramp.h` 保存浮点转速余量，按实际任务周期积分，周期超过 `APP_MOTION_RAMP_MAX_DT_MS` 时按上限计算，避免任务阻塞造成一次性速度跳变。

- 目标增加使用正常加速度，目标降低使用正常减速度；
- 目标改变方向时先降到零，等待现有零速反馈确认后才允许反向；
- 量化不会越过目标或零点；
- 遥控器双轴、HMI 双轴和 CAN 批次使用同一个斜坡批次目标；
- 释放、停车、失联、K5 和复位都会清理斜坡余量；
- 速度写入故障、反馈失效和停车超时升级到既有安全接管/急停路径。

## 4. 驱动器 H06 参数

`H06_05` 根据正常加速度自动换算，`H06_06` 根据所有受控停车路径中最大的减速度自动换算，使驱动器内部斜坡不限制最快的K5停车。当前默认值约为：

- `H06_05 ≈ 24216 ms`；
- `H06_06 ≈ 7265 ms`（当前K5为 `0.50 m/s²`；若K5调整为 `0.60 m/s²`，约为 `6054 ms`）。

主控积分器仍负责正常运行的 `0.15/0.30 m/s²` 以及失联、K5停车的实际减速度，不在停车过程中动态写H06参数。换算值在写入前必须处于 `uint16_t` 的 `1..65535` 范围内。

当前外部脉冲上限仍为 `100 kHz`。按新总传动比，该模式最高约对应电机 `600 rpm`、钢轮约 `218 rpm`、车辆约 `7.85 km/h`，不能覆盖20 km/h目标；RS485速度模式才使用约 `1529 rpm`的车辆运行上限。

## 5. 现场调试顺序

1. 悬空或支撑台验证转速变化和反向零速确认；
2. 空载、直线、干燥钢轨，先限制在输出轴 `30 rpm`（电机90rpm）；
3. 依次提高到输出轴 `60 rpm`、`120 rpm`（电机180、360rpm）；
4. 分别测量正常停车、遥控失联停车和K5停车；
5. 记录实际加减速度、停车距离、前后轮组速度差和滑移；
6. 再做满载、坡道、湿轨和污染轨面测试；
7. 未确认无滑移、抱死、轮缘爬轨和明显点头前，不提高运行速度。

整车含人按 `360 kg` 校核，不直接进入斜坡算法。牵引力和制动力校核可使用 `F = m a`，即正常加速约 `72 N`、正常减速约 `108 N`、K5减速约 `216 N`，另行叠加坡度、滚动阻力、风阻和安全余量，并校核轮轨黏着、伺服峰值转矩及机械制动能力。

以上是软件第一版调试设计，不是实体急停、STO 或安全认证结论；任何真实故障、反馈不可信或停车超时仍优先进入原有急停路径。
