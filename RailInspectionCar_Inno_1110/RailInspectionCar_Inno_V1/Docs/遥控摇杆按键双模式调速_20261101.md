## 操作方法

1. K5 长按运动授权成功后默认 JOY、公共目标为零。原摇杆映射与 K5 停车功能继续有效。
2. 左摇杆 LV 回中（940～1060，含边界）后短按 K9 进入 KEY，目标从 0.00km/h 开始。LV 未回中时本次操作无效，需重新短按；K9 长按不切换。
3. KEY 下 K1 每次 +0.05、K2 每次 −0.05km/h，范围 −20.00～+20.00。消抖按下立即一步，300ms 后连续更新，自本次消抖按下算起 10 秒累计 400 步；松手不补步。饱和不积存额度。两键冲突暂停，双方释放后接受新操作。JOY 下 K1/K2 不调速，KEY 下摇杆不调速。
4. KEY 返回 JOY 必须两次 K9：LV 回中第一次清零并保持授权、正常减速，显示 KEY W；得到新零命令确认与两轴各两次新零速反馈后显示 KEY R；LV 仍回中再短按 K9 才返回 JOY。即使原来就是零速也如此。没有双击时间窗或操作超时；提前第二次不缓存，必须在就绪后重新短按。K1/K2 有效调速会取消退出准备。
5. 任意模式下 K5 按原保护路径停车；失联、无线重建、撤权或重新授权会清除旧按键目标，恢复 JOY。边界时已经按住的 K1/K2 必须先释放再按。

首页第四行显示 `T:10.05km/h KEY`、`T:0.00km/h KEY W/R` 或 `JOY`；HMI/CAN/CLI 占用时显示对应来源。两位小数直接取 F407 返回整数，CLI 未知目标为 `--`，旧帧显示 UNK，过期数据带 `~`。原 VT 双轴命令折算速度移至速度页末行；原九页和 RA/VA/电压/电流/负载/里程保留。预览在 preview/，使用项目真实 6×8 字模渲染。

10 秒仅约束目标更新。正常加速度保持 0.15m/s²、减速度保持既有配置；实际电机 0→20km/h 的理想加速时间约 37 秒。20km/h 按轮径 185mm、总传动比 8/3 折算约 1529.42rpm，下发对称四舍五入为 ±1529rpm，再走既有同步、限幅、换向过零及加减速链路。

## 实物验收顺序

先抬轮低速测试，记录公共目标、A1/A2 已确认命令及实际反馈，避免把三者混为一个速度。

| 场景 | 预期 |
|---|---|
| 上电 K5 授权 | JOY，公共目标零；摇杆运行 |
| JOY 下按 K1/K2 | 目标不受按键影响 |
| LV 在 939/1061，短 K9；再回中 | 均不切换，回中后须重新短按 |
| LV 在 940/1060，短 K9 | KEY，目标清零；若尚在减速继续正常减速 |
| KEY 单次 K1/K2 | 0.00→0.05→0.00；10.00 下 K2 得 9.95、9.90 |
| KEY 推摇杆 | 目标不受摇杆影响；K9 仍要求 LV 回中 |
| KEY 第一次 K9 | 目标清零、保持 KEY 和授权，显示 W；不直接退出 |
| 未停稳立即第二次 K9 | 忽略，不在停稳后自动切换；显示 R 后再按才退出 |
| 初始零速两阶段退出 | 仍须第一次清零确认、第二次切换 |
| W/R 时 K1/K2 | 有效调速取消退出准备，此后重新两次 K9 |
| 两模式 K5、重复 K5、重新授权 | 原停车功能正常；授权后 JOY，无旧目标恢复 |
| 双键冲突、释放一个、再全释放 | 冲突冻结；仅释放一个不恢复，双方释放后新按有效 |
| 失联／断电重启／无线重建 | 原保护停车，不重放旧目标，重新授权 JOY |
| 长按全量程和反向 | 目标约 10 秒达到 ±20.00（从消抖按下算 ±50ms）；持续饱和后反向第一步立即有效；实际运行遵守正常斜坡与过零 |
| 单轴／双轴反馈异常 | 只检查有效轴掩码；过期、非零、故障或未完成事务不能返回 JOY，异常进入原保护流程 |

10 秒物理按下测试包含约 20ms 消抖；主机测试正负方向首次均为 10020ms。现场应通过 CLI/日志计时主控目标，OLED 回传有调度/刷新延迟，不能用画面首次刷新替代主控目标时间。`remote servo status` 新增 `remote_speed` 行（mode、target_centi_kmh、exit_pending、exit_ready、block）；block 为 0=允许、1=LV未回中、2=等待新零速确认、3=输入无效、4=未激活。
