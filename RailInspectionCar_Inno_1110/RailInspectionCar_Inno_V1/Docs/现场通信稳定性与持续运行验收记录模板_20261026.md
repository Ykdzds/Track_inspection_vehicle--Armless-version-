# 现场通信稳定性与双轴持续运行验收记录模板

## 1. 烧录前冻结

记录 F407/F103/遥控端/HMI23 的工程路径、HEX/BIN/AXF SHA256、配置宏、驱动器参数、烧录日期、操作员和实物读取到的版本横幅。最终 HMI 必须来自 23 号统一状态快照工程；22 号仅作为回退版本。四端哈希必须与《四端版本清单与10条BUG闭环矩阵_20261026.md》一致。

## 4. 故障时间线字段

每次停车保存同一时间基准下的 CAN 抓包、F407 CLI、F103 OLED/串口、遥控回传和 HMI 寄存器快照。至少包含：停车类别、首因、最终因、源、轴、token/generation、目标序号、指令 rpm、实际 rpm、反馈年龄、连续失败次数、Modbus 地址/结果、停车开始/完成时间、失能确认和人工恢复状态。

## 5. 恢复验收

停车完成后确认双轴新鲜零速、无真实故障、失能回读和连续健康观察；旧 K5/旧 CAN 请求必须无效，未回中 K5 必须拒绝。K3/K5/CLI 恢复请求只能进入 READY/REQUESTED/PREPARING/DONE 状态机，DONE 后控制源为空、目标为零，随后分别重新授权；恢复中再次异常必须保持锁定。
