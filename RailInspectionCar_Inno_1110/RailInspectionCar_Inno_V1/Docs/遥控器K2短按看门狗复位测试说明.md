# 遥控器K6短按看门狗复位测试说明

> 2026-10-13按键迁移：物理K5短按受控停车、长按授权；K6短按看门狗测试（默认关闭）；K7/K8短按上一页/下一页。K1～K4无功能但三类事件仍上传。两端固件必须配套升级，升级期间禁止运行；协议无版本协商，旧新混用会功能错位。内部K1枚举/接口及旧文件名仅为兼容保留，实际由K5触发。

日期：2026-10-09。

## 1. 开关与适用范围

`APP/app_config.h`：

```c
/* 是否启用遥控器K6短按看门狗复位测试。 */
#ifndef APP_WDG_TEST_K6_SHORT_ENABLED
#define APP_WDG_TEST_K6_SHORT_ENABLED (0U)
#endif
```

- 默认0：遥控K6短按无控制动作，不改变授权、不急停、不停止喂狗。
- 设置1并重新编译下载主控固件：新的遥控K6短按触发一次真实IWDG超时复位。非法值在编译期拒绝。
- 这是测试开关，验收后应改回0并重新编译下载；必须同时升级本次遥控器固件；32字节控制帧或状态协议格式不变。
- 对象是遥控器K6，不是主控板上的本地KEY_ID_2；本地按键功能保持原状。
- K6长按、双击不触发；遥控端K6仍沿用其现有短按/双击识别等待，不等同于K5的即时短按。
- 不要求遥控运动已经授权，CLI会话期间也可触发。即使关闭遥控运动功能，只要无线快照服务仍正常运行，也可执行测试。

## 2. 执行流程

```text
有效链路、同一无线恢复代次中的新K6短按累计数
→ 锁存本次启动测试请求
→ 撤销遥控及CLI授权，取消运动批次
→ 复用aimtor_emergency_stop关闭本地脉冲，尽力异步失能选中轴
→ IWDG任务不再刷新硬件看门狗，但保持任务调度
→ IWDG真实超时复位
→ 读取IWDGRSTF，原看门狗安全恢复及启动清理
→ 各安全门禁通过后使能零速待机，等待新的授权
```

触发后不能通过K5长按、CLI新会话、保活、模式切换、清停止锁存或迟到应答恢复运动。重复K6事件不重复初始化测试；无线失联、快照过期或无线恢复首帧中的历史K6被消费，不触发测试。

没有调用软件复位，也没有故意阻塞任务或伪造心跳失活。测试请求使喂狗决策直接停止刷新，同时明确执行现有急停路径。普通心跳超过500ms后“急停、记录心跳故障、停止本轮喂狗”的原逻辑保持不变。

当前IWDG配置为分频16、重装载2000；若LSI为32kHz，则从最后一次刷新到复位约1秒，实际取决于LSI频率。喂狗任务250ms检查一次；遥控按键识别、无线传输和任务调度还有各自延迟。不把该时间当成实际停车性能保证。

## 3. 恢复与安全边界

- 不恢复旧速度、旧位置目标、CLI会话或遥控授权。仍须回中并产生新的K5长按，或创建新的CLI会话。
- 仅真正POR执行位置设零；K6制造的IWDG复位不自动清位置。
- 默认开启统一待机时，恢复成功进入使能零速待机；待机宏关闭、只读配置或恢复失败时不自动使能。
- 本测试复位前已执行急停失能，因此不保证覆盖“驱动器仍使能且带速”的内部斜坡恢复分支；该分支须另行独立实测。
- `aimtor_emergency_stop()`不代表电机已停稳或驱动器已确认失能；总线失效时只能尽力发送。通信故障、DI3及硬件安全门禁仍独立生效。
- 不使用Flash、RTC或备份寄存器保存测试来源。复位后只能确认硬件IWDG复位，不能据此声称一定由上一次K6触发。
- 实物测试必须固定车辆，先零速后低速，保留独立硬件急停；不能用本功能替代DI3或硬件安全链路。

## 4. 诊断与操作

`status`新增：

```text
wdg_test_k6_enabled=0/1 requested=0/1 active=0/1
```

`requested=1`表示已接收测试请求；`active=1`表示IWDG任务已进入不喂狗分支。诊断位`APP_DIAG_WDG_TEST_REQUESTED`为bit9，本次启动RAM现场detail为2，表示遥控K6测试。

复位后`requested/active`回到0，既有`wdg_reset=1`表示本次硬件复位原因包含IWDG。不会将清零的RAM诊断误报为跨复位历史。等待时间短，串口未必来得及输出请求阶段全部状态。

建议步骤：

1. 默认宏0下载，短按遥控K6，确认既不复位也不撤权。
2. 改宏1重新下载，保持链路正常、车辆固定，短按K6一次，观察复位。
3. 复位后发送`status`，检查`wdg_reset=1`、看门狗恢复/启动停车/待机就绪，且未授权、速度0。
4. 保持遥控器通电，确认不因重传旧事件反复复位；新K5长按后才允许运动。
5. 低速遥控和CLI期间分别测试K6，确认撤权、关闭本地输出及复位后不恢复旧目标。
6. 测试结束改回宏0并重新编译下载。
