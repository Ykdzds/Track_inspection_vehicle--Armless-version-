## 记录如何定位

- `FIRST`独立保存首次停车事件，包含来源、reason、序号和减速度。更大的减速度仍沿用原控制逻辑，升级以独立事件记录，不能将升级reason当首因。
- 接收、入邮箱、消费、拒绝、响应提交和响应完成分别记录。DWT周期计数约25.6秒回绕，必须结合HAL毫秒时间和boot ID；原始DMA捕获时间并不等于物理线路最后一位的精确时间。
- `SCREEN`为37号冻结的两页24寄存器。相同event ID关联，两页齐全时 `mask=3 incomplete=0`；缺页不得作为完整现场解释。协议详见37号交付说明及本目录日志字段说明。
- `MEM free/min`是FreeRTOS堆当前/历史最小剩余字节；`STACK bytes`是12个任务的历史最小空闲栈字节，NA表示无效。链接静态余量与这两者含义不同。
- boot ID变化、uptime回退或新增复位记录说明出现新启动。无复位记录不能用于否定冷复位，因为掉电/BOR会使保留SRAM失效。
- 输出限速6000字节/秒，缓冲拥塞不等待；检查 `LOGGER`中的丢失计数。首因和屏端页有独立存储与重试，普通事件过载可能丢失，并显式计数。
