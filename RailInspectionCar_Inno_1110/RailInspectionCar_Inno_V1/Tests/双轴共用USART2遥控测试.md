# 双轴共用USART2遥控测试

更新日期：2026-10-06。本文件记录软件验证结果与待执行的实物测试，不代表实物验收通过。

## 固件与控制规则

- 默认查询与控制配置均为 BOTH，关闭只读模式。
- 左轴地址1、右轴地址2，共用USART2，115200、8N1。
- LV范围0～2000映射至-600～600rpm，940～1060为零速区，保留斜坡。
- 上电不授权。LV回中后长按K1，各类复位安全流程成功后的使能零速待机直接接管；待机不适用时按原失能、配置、核验及零速给定、使能流程进行。两轴状态有效且零速后共同授权。
- 任一轴配置或使能失败，结束本次授权并联停，不自动重复授权。
- 短按K1或无线150ms无合法帧时撤权，用独立停车参数受控减速、取得每轴两次新零速反馈；K1停稳后失能锁存，失联停稳在统一使能待机适用时保持零速使能。真实故障、通信连续失败达到3次或关键状态年龄达到500ms，仍立即急停锁存。
- 恢复无线或总线不自动恢复运动，需回中后重新长按K1。

## 总线调度

同一时间仅允许一个待应答请求。失能优先于配置与运动；关键回读按轴和速度/故障类型轮转，速度写入按轴轮转。

关键回读目标周期20ms，后台回读目标1000ms，通信任务延时配置1ms。现有Modbus事务含帧间延时和应答等待，因此这些配置不代表实际每1ms发报文，也不保证每个回读都能达到20ms。

压力测试发现，双轴关键回读持续到期时，绝对回读优先会使速度写入饥饿。修正为一轮关键回读后允许一个速度事务，随后重新优先关键回读。未扩大通信故障阈值。

正常速度批次锁定共同基础斜坡目标。成功轴不重复写入，失败轴按原策略重试；两轴均成功后推进共同 command。同步关闭时完成批次 command_diff=0；同步开启时为整数补偿量的负两倍。停车批次另行锁存，不带P补偿，失败不沿用普通重试，而是立即急停。

- K1独立受控停车后失能锁存、无线独立停车、恢复后不自动授权。
- 异步速度写入失败重试、成功轴不重复写入、未完成批次期间改变LV。

## 现场操作

两轴处于安全测试工况，确认地址与方向后逐条发送：

```text
status
comm stat
servo probe
servo current status
remote servo status
```

确认 query=both、控制掩码0x03、两轴在线且故障码为0。LV保持940～1060，长按K1，等待 authorized=1，以及左右均 enable=1、verify=1、mode=speed。

依次测试低速正转、回中停车、反转、连续调速至少5分钟。期间重复读取：

```text
remote servo status
status
comm stat
```

检查共同基础目标一致、完成批次 command_diff与同步开关及整数补偿一致、左右关键状态年龄目标小于100ms且始终低于500ms、无线 max_gap 小于100ms、无意外锁存或看门狗复位。actual_diff仅诊断，不作为停车条件。

随后分别测试短按K1、重新授权、遥控器关机和单轴通信断开。两轴任意 stop/disable、servo current stop/disable、servo emergency、motion stop 在遥控接管期间均按共同急停处理。

批次诊断包含 active、success_mask、age、response_gap；response_gap是通信服务观察到两轴成功应答的时间间隔。stop_axis_mask为0表示无线或手动来源，0x01为左轴，0x02为右轴，0x03为两轴。

## 必须实测的安全边界

无线150ms是失联判定阈值，不等于电机实际停止耗时。应另行测量判定、首条停车命令、零速反馈、失能报文和机械停止的时间。详细规则与实物记录见 `遥控独立受控停车测试.md`。

RS485断开的轴不能保证收到停车或失能命令。软件会撤销共同授权、锁存并尽力失能，另一可通信轴应停止。若要求断线轴可靠立即停止，需要驱动器通信看门狗或独立硬件停止链路。

## 115200升级检查与对比记录

### 定脉冲中断回归修复

现场反馈升级后定脉冲不停，代码检查发现CubeMX重新生成删除了TIM9/TIM11的NVIC使能和计数中断入口。PWM仍输出而计数无法推进，因此无法触发到数停止；这不是115200波特率本身引起。此次恢复两个共享中断，并在CubeMX配置启用优先级4、子优先级0；计数调用及上电PULSE推挽低电平接管放入USER CODE保护区。

`Tests/check_pulse_integration.ps1`检查CubeMX中断配置、NVIC、入口和上电引脚保护区，并接入主机回归。脉冲测试现在编译生产中断文件并链接两个真实入口，覆盖计数推进、无新更新标志不重复计数、到数停止、旧命令禁止重启及方向保持。主机回归已通过，不代表硬件中断吞吐量和实际脉冲数量已验收。

本轮修复后Keil全量编译结果：LEFT_ONLY、RIGHT_ONLY、BOTH均为0错误、0警告，最终保留BOTH并生成双轴HEX。尚未下载或进行本轮实物停止验收。

下载后先测试安全短脉冲，观察计数增长，再执行`servo left pulse forward 30000 200000`。最终必须达到`pulse=200000/200000 out=0 reached=1`，保持使能和最后方向，反馈满足条件后才报告停止确认。覆盖左右轴、双轴、正反转、新命令及急停；示波器或外部计数设备检查输出数量，特别检查双轴100 kHz是否漏计。30000 Hz对应180 rpm，但加减速使完整运动时间不同于恒速20圈计算值。
