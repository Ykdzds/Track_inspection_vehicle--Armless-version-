# Flash 保存门禁与 NRF 恢复状态修复

基线：`8883212`。版本：`sync-tune-1.6`。本轮没有操作串口、烧录设备或执行实机 Flash 保存。

## 实现

- 保存门禁和 kind21 只读快照共用生产条件采集与评估；查询不维护零速计时。历史 NRF 诊断保留，当前状态未知、失效或未验证恢复时仍禁止保存。
- NRF 失败从本次观察开始计时，连续1000 ms才置当前故障；任意就绪丢失、SPI/DMA/校验/恢复计数变化或状态服务间隔达到100 ms撤销恢复确认。
- 恢复要求稳定至少1000 ms且完成两轮真实配置检查。原驱动每1000 ms检查，通常约2秒或更久；不新增SPI/RS485事务。
- 新能力0x80，`tune gate REQUEST BOOT CRC`，schema1、kind21、112字节载荷；原协议与HMI地址不变。kind18 page3预留区补充NRF计数，有效位0x100。
- 全部撤权、待运动请求、停车状态、100 ms反馈年龄、500 ms零速、维护锁、故障及看门狗要求保留。自己的保存锁仅允许本事务继续，外部锁拒绝。仍逐字写入、最后提交、回读验证，不增加擦除或自动重放。

## 软件验证

`run_flash_gate_tests.ps1` 使用实际生产 gate_collect 与 gate_evaluate，模拟所有门禁输入、99/100 ms年龄、499/500 ms零速、回绕、只读查询、锁竞争、持锁写入成功及中途失效保留旧参数。

`run_sync_storage_tests.ps1`、`run_tune_tests.ps1`、`run_tune_diagnostics_tests.ps1` 通过：32处逐字失败、半写/CRC/提交损坏、身份/版本、满空间、事务关联、126字节门禁帧、boot/CRC/格式和诊断页映射。

`run_current_watchdog_tests.ps1` 通过，新增真实健康模块 NRF 测试覆盖瞬态/持续失败、真实配置恢复、历史保留、服务中断、回绕与零时间。

串口DMA、快照、生产运动保护、NRF DMA/IRQ、HMI Modbus、CAN/HMI/遥控、双轴模式、安全停车、正常服务时序、ARM3输入/端口、通信按键和故障保留回归通过。快照脚本补齐既有ARM3链接依赖后重跑通过。

正式Keil工程构建：0错误、0警告。程序未侵入0x080A0000参数区；512字节UNINIT故障区有效。静态任务栈余量均不低于256字节；Flash编程例程位于0x20000000，常量池位于SRAM且无函数调用。静态检查不替代实物栈高水位与写入时延测量。

详细本轮输出：`8.双轴调试上位机/release/sync-tune-1.6/validation/final_1.6`。上位机测试、固件与EXE哈希见该版发布报告和清单。
