# CLI独立授权测试

日期：2026-10-07。

## 1. 自动化入口

```powershell
& ./Tests/run_tests.ps1
& ./Tests/run_cli_session_tests.ps1
& ./Tests/build_cli_session.ps1
```

专项会话测试链接生产会话、伺服、调试、运动、脉冲中断及Modbus代码，以模拟寄存器应答验证状态推进；覆盖LEFT_ONLY、RIGHT_ONLY、BOTH，调试开关0/1及只读0/1，共12组。

Keil脚本进行三种轴配置乘调试开关0/1的六组全量编译，临时覆盖工程编译宏，最终恢复原工程内容并重新编译现场配置。脚本运行期间不要同时修改Keil工程文件或运行另一个编译实例。

## 2. 已覆盖的断言

| 项目 | 检查内容 |
| --- | --- |
| 未授权及开关 | 未授权底层速度拒绝；关闭调试和只读配置不能申请 |
| 控制源互斥 | 遥控授权时拒绝申请；CLI期间长按不抢占、无线失联不撤CLI |
| 轴选择 | 三种轴配置；BOTH运行时分别选择两轴；另一轴保持零速使能 |
| 三模式 | 速度接管、内部位置触发、单轴脉冲输出；关键查询与位置请求公平 |
| 非目标轴 | 拒绝速度、核验及底层脉冲启动；无非目标运动输出 |
| 停止优先 | 未启动请求被取消；受理停止立即撤普通权限；重复停止不延期 |
| 会话保活 | 匹配ID、旧ID拒绝、状态不续期、30秒超时及Tick回绕 |
| 退出 | entering期间off不授权；各类复位适用待机均恢复；关闭待机时退出失能 |
| 锁存 | CLI自身K1锁存可显式新会话恢复；遥控K1人工锁存拒绝新会话；真实故障不能用on或后续人工事件绕过 |
| 确认失败 | 持续非零反馈5000ms后失败，不虚报停稳 |
| 遥控事件 | 新短按触发一次；历史长按持续消费；退出后需新长按 |
| 无线回传 | CLI三模式及停车/K1状态；无遥控授权位、无旧遥控命令冒充 |
| 原有回归 | P同步、共同斜坡、受控停车、位置里程、DMA、启动安全及只读 |

自动化使用模拟外设，不验证实际电机减速、机械保持力或带载到位。

## 3. 实物测试准备

固定车辆、限制车轮运动范围，准备独立停止措施。先低速、短行程验证，不在轨道自由运行状态下启用CLI会话。

上位机每1秒发送匹配会话号保活；记录每次返回的会话号，不能硬编码为1。串口断开并不等于立即停车，最长可能等到保活超时。

保持现场轴配置、停车减速度及同步参数；若测试另一轴或BOTH，应明确修改配置并独立烧录，不由本轮自动恢复为BOTH。

## 4. 实物用例

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| H01 | POR上电，不申请会话发送速度/位置/脉冲 | 明确拒绝；原待机使能保持 |
| H02 | on目标轴，持续保活 | queued后转ready/authorized；另一轴保持零速 |
| H03 | 速度正反向低速测试，stop | 停止优先；反馈停稳后会话ready |
| H04 | 停止后切位置，短行程测试 | 目标轴失能切换、核验后使能；另一轴无运动 |
| H05 | 停止后切脉冲，短脉冲测试 | 只目标轴输出，原到数及停稳确认正常 |
| H06 | 向非会话轴发送运动、mode、enable、维护 | 拒绝；查询正常 |
| H07 | 遥控长按、遥控断电 | 不抢占CLI、不单独停止CLI |
| H08 | 新遥控K1短按 | CLI立即撤权锁存，电机尽力失能 |
| H09 | 人工disable/emergency或停止保活 | 锁存；旧ID保活无效；满足安全条件后新on显式恢复 |
| H10 | 会话运行及准备阶段off | 取消旧目标，停稳；适用时恢复速度零速使能待机 |
| H11 | 按键/软件/看门狗复位后会话off | 安全流程成功且待机开启时恢复使能零速，仍未授权 |
| H12 | 单轴离线、真实故障、反馈过期、恢复失败 | 不虚报ready/停稳；新on不能绕过真实故障 |
| H13 | CLI退出后历史K1长按及摇杆非中位 | 不授权；需回中并新长按 |
| H14 | 正常遥控K1保持后申请CLI | 拒绝创建，不能绕过遥控人工锁存；查询、停止和失能仍允许 |

每项记录USART1发送丢弃增量、USART2通信错误增量、关键反馈年龄、任务心跳及栈余量；BOTH模式确认另一轴没有运动写入，遥控回归时确认同步配对没有持续退化。
