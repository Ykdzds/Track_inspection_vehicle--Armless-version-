# 双轴位置差与里程监控调试说明

更新日期：2026-10-05。

本说明对应独立模块 `APP/app_position_monitor.c/.h`。本轮只增加监控和诊断，不增加位置闭环、位置差补偿、位置超差报警或自动联停。本文中的软件测试结果不能替代实物验收。

## 1. 配置和计量口径

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `APP_POSITION_MONITOR_ENABLED` | `1U` | 改为0并重新编译后，不累计、不配对，恢复原后台调度 |
| `APP_POSITION_MAX_AGE_MS` | 1500 ms | 最大位置样本年龄与连续采样间隔 |
| `APP_POSITION_MAX_SKEW_MS` | 200 ms | 最大双轴位置配对错时 |
| `APP_POSITION_JUMP_MARGIN` | 100计数 | 合理跳变检查的计数容差 |
| `APP_POSITION_LEFT/RIGHT_COUNTS_PER_REV` | 10000 | 每电机转反馈计数，不是外部脉冲计数 |
| `APP_POSITION_LEFT/RIGHT_SIGN` | +1 | 前进时两轴统一正方向，仅允许±1 |
| `APP_POSITION_LEFT/RIGHT_WHEEL_DIAMETER_MM` | 185 mm | 两轴可独立校准 |
| `APP_POSITION_LEFT/RIGHT_GEAR_NUM/DEN` | 1/1 | 电机转数/车轮转数 |

当前工程保留BOTH、速度P同步开启、Kp=0.30、超差联停关闭、同步周期打印关闭；这些既有参数不因位置监控而调整。

按当前机械配置：

```text
每电机转 = π × 185 mm = 581.194641 mm
每反馈计数 = 0.058119464 mm
净位移 = 带符号计数增量之和 × 每计数距离
采样累计行程 = 计数增量绝对值之和 × 每计数距离
```

双轴车辆估算值为两轴对应距离的平均值，单轴为选中轴的估算值，来源用 `source_mask` 标记：1左轴、2右轴、3双轴。

所有距离都是**轮转估算值**。约1秒一次位置采样内发生往返运动时，采样累计行程可能少计；滑移、轮径差、传动误差及弯道也会影响估算。不得直接将其认定为真实车辆里程。

## 2. 使用方法

```text
position status
position trip reset
status
remote servo status
comm stat
```

`position status` 的主要字段：

| 字段 | 含义 |
| --- | --- |
| `state`、`valid`、`age` | 当前记录状态、有效性、接收样本年龄 |
| `raw`、`seq`、`gen` | 原始位置、有效应答序号、驱动器设零代次 |
| `boot_net`、`boot_path` | 本次启动净位移、采样累计行程，米，三位小数 |
| `trip_net`、`trip_path` | 可手动清零的分段净位移、采样累计行程 |
| `trip_anchor` | 分段清零后正在等待下一有效位置锚点 |
| `incomplete`、`gaps` | 历史存在未知区间、丢失区间次数 |
| `relative valid`、`gen`、`auth_gen` | 相对位置差有效性、软件基准代次、授权代次 |
| `raw_diff` | 最近已接受两轴原始位置的直接差，仅作诊断，不代表同步误差 |
| `L`、`R`、`diff`、`diff_mm` | 本轮基准后的两轴相对计数、计数差和位移差 |
| `seq`、`age`、`skew` | 配对使用的序号、较早样本年龄、错时 |
| `rate_valid`、`rate_mm_s` | 有效相邻配对的差值变化率 |
| `skew_est_valid`、`skew_est_mm` | 错时影响估计的有效性及毫米估计值 |
| `reset_pending`、`resets`、`reset_rejected` | 分段清零申请及执行结果 |

无效字段保留末次值供诊断，但只有对应 `valid=1` 时才能视为当前有效数据；LCD无效项显示 `--`。`incomplete=1` 不会在通信恢复后自动消失，表示本次启动历史不能宣称完整。

分段清零只允许未授权、无运动或模式事务、PULSE关闭、选中轴在线且新鲜反馈速度为0。命令返回 `queued` 仅表示申请接入；运动任务重新检查后才执行，以 `resets` 增加确认。请求后状态变为不安全时计入 `reset_rejected`。

清零仅修改RAM，不写H05_30，不清启动累计值。为避免清零前未采样移动进入新分段，下一有效位置只重建分段锚点；跨该边界的未知行程不补算，启动累计仍按原轨迹处理。

## 3. 启动与连续性

启动安全停车、看门狗恢复、上电设零门禁完成后，等待新位置建立里程起点。启动阶段旧缓存和清理动作不计入后续行程。

设零流程开始即递增位置代次并失效旧缓存，即使写应答丢失，也不把可能已执行的设零跳变当作运动。

离线、过期、序号异常、缓存缺失或不合理跳变时保留已知历史并标记不完整。恢复首个有效位置只重建锚点，不补算未知区间。异常跳变样本不作为有效行程，后续有效样本重新锚定。

位置监控异常不设置红灯、不急停、不失能；既有通信故障和安全停车机制独立运行。

## 4. 相对位置差与显示

所有模式采集选中轴里程，包括未授权使能待机、遥控和CLI速度/位置/脉冲测试。相对位置差只在BOTH、非只读、遥控ARMED/RUNNING且授权、速度模式核验与启动/硬件门禁通过时计算。

每次授权等待双方新位置建立软件基准，不写驱动器设零指令。单侧新样本暂存，从两轴缓存中取错时最小的一对；每组只消费一次。退出授权、急停、模式变化或轨迹不连续后，当前位置差失效但保留末值，下一符合条件的会话建立新基准。

不对位置进行速度外推。错时影响估计仅在两轴速度反馈有效且年龄小于100 ms时显示，采用最大轮转线速度乘位置样本错时。它不是误差保证值。例如轮转速度对应20 km/h时，200 ms错时对应约1111 mm，不能把该差值直接认定为真实同步偏差。

LCD页面循环为：

```text
伺服 → 遥控 → 位置里程 → 伺服
```

开启原 `APP_REMOTE_SERVO_SYNC_DEBUG_ENABLED` 后，TAB调试原11列顺序不变，末尾追加：

```text
POS_GEN POS_VALID L_POS R_POS L_REL R_REL DIFF_MM TRIP_M POS_SKEW_MS L_POS_SEQ R_POS_SEQ
```

仍通过USART1 TX DMA发送；位置约1秒更新，100 ms打印的重复位置可用序号识别。容量不足整行跳过，计入 `comm stat` 的 `sync_debug_skipped`。长状态响应追加的简短位置摘要不足容量时也整体跳过，计入 `position_summary_skipped`；详细位置使用独立命令读取。

6. 急停、K1重新授权、正常失联停车、待机扰动，确认原安全策略不因监控而改变。
7. 断开并恢复通信，确认记录不完整、恢复只锚定、不虚构未知行程；继续观察原通信安全停车。
8. 未授权零速执行分段清零，确认启动累计不变；授权、运行、反馈陈旧或事务忙时必须拒绝。
9. 开启TAB调试并连续查询，记录USART1 `dropped`、`peak`、跳过行计数及USART2通信错误增量。
10. 已知长度轨道校验轮转估算，直线与弯道分开记录，并记录负载、打滑和轮径标定信息。

## 8. 三组现场快照与待排查问题

| 指标 | 第一组 | 第二组 | 第三组 |
| --- | --- | --- | --- |
| 左/右原始位置 | 0/0 | 367222/367690 | 137169/137561 |
| 车辆启动采样累计行程 | 0.000 m | 11.495 m | 11.496 m |
| 左/右历史不完整标志 | 0/0 | 1/1 | 1/1 |
| 左/右丢失区间次数 | 0/0 | 2/2 | 4/4 |
| 位置差基准代次 | 0 | 4 | 8 |
| 相对位置差有效 | 0 | 1 | 1 |
| 相对位移差 | 无有效结果 | +0.058 mm | +1.162 mm |
| 位置样本错时 | 无有效结果 | 25 ms | 65 ms |

三次查询时，两轴均使能、零速、无故障；USART1 DMA丢弃和错误、USART2超时和CRC错误均为0。第一组未授权时不建立相对位置差基准，符合设计；首次分段清零申请后，后续快照的 `resets=1` 确认执行。第二、第三组仍授权，分段清零被拒绝符合门禁。

重要待排查问题：第二组到第三组原始位置分别减少230053、230129计数，按当前配置约对应13.371 m、13.375 m反向净位移，但已记录累计行程只增加2、19计数。若期间没有驱动器位置重置，则该段运动存在明显漏记；当前 `tracking valid=1` 仅表示当前反馈有效，不能覆盖 `incomplete=1` 所表示的历史缺口。

三组设零代次均为1；第二、第三组授权代次同为4，位置差基准代次却由4增至8。因此小的相对位置差只能说明最近重建基准后的有效区间，不能代表完整运动过程的同步精度。仅凭停稳快照不能确定缺口来自过期、序号不连续、异常跳变还是其他原因，不直接归因为通信丢包。

后续应增加断点原因分类和断点前后序号、采样间隔、原始增量及允许增量诊断，并低速固定圈数复测。该问题尚未修复，本次提交保留此限制；不修改P同步参数、不增加积分或位置联停。
