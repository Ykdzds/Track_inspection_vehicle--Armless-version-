# 定脉冲停止反馈复测

## 本次软件处理

- TIM9/TIM11定脉冲到数后关闭对应PWM通道、更新中断并清零CCR；两轴均无输出时关闭公共门控。
- 到数锁存阻止后台重新写入旧频率，不调用伺服失能接口。
- 完成判定需要输出关闭之后的新速度和位置反馈，实际速度为0、位置处于目标容差内，并连续满足位置稳定条件。
- 位置主动回读目标周期20ms，稳定条件为3次相邻新位置反馈不变；共享RS485实际回读间隔由事务调度决定。
- 完成等待超时3000ms后报告FAULT和timeout，不伪装成完成；本地输出保持关闭。真实驱动器故障或通信失效仍走原有安全停车路径。

## 单位前提

10000个外部指令脉冲/圈不等于编码器物理分辨率。当前目标位置计算假设驱动器实际位置寄存器与指令脉冲采用相同单位和方向。

先以低速、小行程记录位置增量，确认10000个指令脉冲是否对应位置寄存器增量10000，正反向符号是否一致。未确认时不能把位置增量200000直接认定为20圈，也不要为消除报警而扩大位置容差。

本实现以定时器输出计数到数为停止条件，以编码器反馈为完成确认条件；不是等编码器到达目标后才关闭脉冲。后者会受RS485回读延迟影响，不能保证准确输出脉冲数。

## 现场步骤

电机处于安全测试工况，使用匹配左轴配置的固件。双轴配置使用`servo current pulse`测试两轴，不将单轴命令当成双轴测试。

```text
servo left pulse forward 30000 200000
servo left status
servo current status
comm stat
```

命令受理后等待运行结束，再连续采集至少5秒状态。反向复测：

```text
servo left pulse reverse 30000 200000
```

应观察：

```text
pulse=200000/200000
out=0
reached=1
stop_confirmed=1
timeout=0
actual_rpm=0
enable=1
```

同时确认`pulse_pos`中的start、now、delta、target、error和stable：位置增量与本次方向相符，完成后位置不再持续变化。

## 仍缓慢转动时

- `out_hz=0`但位置持续变化：尚未确认机械停止，采集完整状态并用示波器核查驱动器输入端是否仍有脉冲。软件频率字段不能替代物理测量。
- `actual_rpm=0`但位置持续变化：速度寄存器的整数分辨率可能掩盖低速运动，不能只看LCD的RPM。
- `timeout=1`：软件明确未确认完成；保持输出关闭，不自动补发位置误差脉冲。
- 物理脉冲已停止而位置仍变化：核查驱动器位置指令滤波、电子齿轮、指令来源和机械负载。不得在缺乏厂家确认时猜测写入滤波或停止寄存器。

主机测试只能验证模拟反馈下的软件行为，不能证明现场电机的慢转原因已经消除，也不能替代示波器脉冲计数验收。
