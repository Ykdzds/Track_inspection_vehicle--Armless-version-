# 看门狗复位受控减速与统一待机测试

日期：2026-10-08。

## 1. 自动化入口

```powershell
./Tests/run_tests.ps1
./Tests/build_watchdog_recovery.ps1
```

主机核心直接编译生产伺服、运动、脉冲及Modbus代码，替换硬件和RTOS依赖；驱动器模拟在目标0写入后保持非零实际速度，并随时间按独立减速参数下降，不用“写零即实际零”替代测试。

Keil矩阵覆盖LEFT_ONLY、RIGHT_ONLY、BOTH，待机开关0/1及只读0/1共12组；结束恢复原工程字节并全量编译当前现场配置。期间不可同时运行另一Keil编译或修改工程文件。日志：`$env:TEMP/wdg_matrix_<axis>_<hold>_<readonly>.log`及`wdg_final_current.log`。

## 2. 自动化检查项

| 项目 | 检查内容 |
| --- | --- |
| 事务顺序 | 带速时先独立减速写/回读，再零目标；实际停稳前不失能、不切来源、不恢复正常参数 |
| 正反向 | ±600rpm保留原使能减速，停稳后恢复正常H06_06 |
| 零速确认 | 两次新应答至少20ms；同一事务重复应答即使延迟25ms也不计第二次 |
| 异常 | 非速度模式、错误来源、减速回读不符、故障、急停、减速不下降超时 |
| 通信 | 初始离线与减速中离线；另一在线轴仍有进展；无法通信不能宣称已失能 |
| 时间 | 32位Tick回绕；600rpm默认确认期限8000ms；准备和减速期限分离 |
| 写失败 | 有界重试、零指令丢应答、失能失败锁存，旧应答不能恢复取消序列 |
| 复位 | POR、按键、软件、IWDG、WWDG及混合标志；非POR不设零，成功后统一待机 |
| 配置 | 三种轴配置、待机开关0/1、只读；非法减速0/65536及余量0编译拒绝 |
| 回归 | CLI、遥控共同斜坡、P同步、独立停车、位置里程、USART DMA及NRF回传 |

## 3. 实物用例

先固定车辆、限制运动区域，准备独立DI3或硬件停车措施。先低速，再逐级升速；不得仅为触发看门狗而删除复位前心跳失活保护。若复位前已被急停失能，记录并单独验证原清理路径，不宣称验证了带速斜坡。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| H01 | POR、按键、软件复位 | 安全清理后选中轴使能零速，旧授权/速度不恢复；仅POR设零 |
| H02 | 合规RS485速度模式下，低速触发看门狗 | 读状态、独立减速核验、写零顺序正确，带速阶段不主动失能 |
| H03 | 正反向逐级至600rpm | 记录实际减速曲线；默认理论6秒，不把写零应答当停稳 |
| H04 | 看门狗复位前已失能 | 原清理与零速确认后待机，不带速重新使能 |
| H05 | 非速度模式带速、来源不符 | 恢复失败，尽力失能锁存；不会改模式后带速使能 |
| H06 | 单轴掉线、减速回读不符、故障 | 不虚报停稳/恢复/待机；不得通过K1或CLI重新授权绕过 |
| H07 | 减速中人工急停或DI3急停 | 原安全保护抢占，禁止自动重新使能 |
| H08 | 零速不能达到或通信中断 | 到期/过期失败；没有通信不能保证驱动器已经停止 |
| H09 | 成功待机后正常遥控及CLI退出 | 新授权才运动；正常退出与失联停稳恢复适用待机 |
| H10 | 关闭待机、只读及单轴固件 | 不新增自动使能/写操作，不访问未选轴 |

每项保存：复位原因、两轴恢复阶段、初始指令/实际速度、H06_06写与回读、零目标应答时刻、实际零速两次应答时刻、清理/待机完成时刻、驱动器报警及USART2错误增量。对照任务心跳、栈余量、同步配对和USART1丢弃增量。

恢复后的DI3接线状态及驱动器使能实际行为须单独核验。软件测试不能证明独立硬件SON反馈、轮轨制动力、机械静止或整车停车距离。
