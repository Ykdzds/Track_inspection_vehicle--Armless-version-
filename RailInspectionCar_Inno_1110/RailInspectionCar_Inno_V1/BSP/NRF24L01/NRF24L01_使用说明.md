# NRF24L01接收功能使用说明

> 本文后续内容保留早期只接收阶段记录，任务及安全行为部分已过时。2026-10-06起当前工程使用SPI2非阻塞DMA，并可配置ACK Payload状态回传；实物联调请以`Docs/NRF24L01主控状态回传非阻塞实施说明.md`及现有遥控安全门禁为准。当前遥控失联会执行既有停车策略，不能按本文早期“失联不停车”描述验收。

## 固定硬件配置

| 信号 | F407引脚 |
| --- | --- |
| CE | PE13 |
| CSN | PE14 |
| SCK | PB10 |
| MISO | PB14 |
| MOSI | PB15 |

SPI2使用主机、8位、MSB优先、Mode 0配置。无线参数固定为：

- 地址：`11 22 33 44 55`
- 射频信道：`0x02`
- 速率：2 Mbps
- 接收管道：Pipe 0
- 固定载荷：32字节

## 协议校验

接收模块只接受完整合法帧：

- 字节0～1：`A5 5A`
- 字节2：版本`01`
- 字节3：类型`01`
- 字节4：帧序号
- 字节5：有效长度`17`（十进制，即`0x11`）
- 字节6～13：四路摇杆，大端`uint16`
- 字节14～19：短按、长按、双击位图
- 字节20～21：事件批次号，大端`uint16`
- 字节22：事件有效标志
- 字节28～29：CRC16-CCITT-FALSE，大端，计算范围为字节0～27
- 字节30～31：`0D 0A`

注意：协议正文中的有效长度`17`是十进制值，不是十六进制`0x17`。

## 任务和失联

`nrf_task`每5 ms轮询一次接收FIFO，合法帧才会刷新摇杆、事件和接收时间。连续300 ms没有合法帧时显示为失联，失联只记录和显示，不自动停止伺服，也不执行任何遥控器控制动作。

事件位图覆盖K1～K12：

- 低字节/低4位：K1～K12中的对应位；
- `S`：短按；
- `L`：长按；
- `D`：双击。

相同事件批次号只计数一次。帧序号和事件批次号按无符号差值处理回绕。

## LCD页面

- 页面0：现有伺服、RS485和系统诊断界面。
- 页面1：NRF遥控器数据显示界面，显示四路摇杆、短按/长按/双击位图、帧序号、事件批次号、接收帧数、丢帧数、CRC错误、格式错误和失联状态。

PC13短按执行普通停车，长按执行急停，双击在页面0和页面1之间切换。PD10、PD11仍作为输入扫描，但不再触发底盘停车。

## 上板验证顺序

1. 下载程序并上电。
2. 检查LCD页面0能够正常刷新。
3. 双击PC13，确认切换到NRF页面；短按和长按分别确认普通停车与急停。
4. 打开遥控器，确认`INIT`正常、`LINK:OK`、年龄持续刷新。
5. 操作四路摇杆，确认数值变化。
6. 依次短按、长按、双击K1～K12，确认对应位图更新。
7. 断开遥控器或NRF通信，等待约300 ms，确认显示`LINK:LOST`且年龄持续增加。
8. 确认上述操作不改变伺服使能、速度、位置和脉冲输出。

首次实物测试建议同时通过调试串口记录LCD刷新、复位和健康监控信息。当前工程已完成主机协议测试、核心回归测试、只读轴隔离测试和RS485接收测试；NRF射频链路、LCD实际显示和PC13实物按键仍需在目标硬件上验证。
