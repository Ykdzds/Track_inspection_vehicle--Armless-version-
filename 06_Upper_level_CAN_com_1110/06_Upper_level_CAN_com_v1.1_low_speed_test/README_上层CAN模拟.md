# F103 上层 CAN 只读模拟节点

## 运行范围

上电自动广播上层启动公告（0x102，500 ms）、业务心跳（0x100，100 ms），按 V1.0 完成 boot 对回显、分段邀请校验、确认与连续三次新心跳判定。会话确认后，通过 0x310/311/312 发布 32 字节能力记录。

运行状态为 WAIT_BOOT → WAIT_INVITE → WAIT_CONFIRM → WAIT_HB → READY。BOOT_ERR 表示启动号持久化失败，协议发送关闭；VER_ERR 表示未连接时收到不兼容主版本。

只具备基本协议、分段协议、通信统计能力（0x00800003）；采集、存储、相机、定位、运动能力均关闭。数据源位图为 0，录制状态为 0xFF 未知。禁止发送 0x080/110/111；驱动发送白名单只有 0x100/102/104/105/310/311/312。TB6612、按键演示从 Keil 源码组移除，不初始化 TIM2/3/4，不启动 PWM。原电机 GPIO 保持低电平，不存在运行按键任务。

本工程只修改 F103 模拟端，没有修改 STM32F4 主控。原 F4 只有 CAN 初始化时，F103 将停留在 WAIT_BOOT，不能因 CAN ACK 显示业务在线。F4 须另行实现协议业务，并与本工程统一到 500 kbit/s；原 875 kbit/s 配置不能直接联调。

## 接线与配置

- CAN RX=PA11，TX=PA12，经外部 CAN 收发器连接 CANH/CANL；非隔离连接确认参考地，终端按实际拓扑配置。MCU 引脚不能直接连接 CANH/CANL。
- F103 APB1=36 MHz，Prescaler=4、BS1=15、BS2=2、SJW=1，500 kbit/s，采样点 16/18≈88.9%。不要照搬 F407 的 APB1=42 MHz 分频参数。
- USART1 TX=PA9，RX=PA10，115200、8N1、无流控；接 3.3 V USB-TTL，串口地共地。
- OLED I2C1=PB8/PB9，400 kHz，地址 0x3C（HAL 使用 0x78），128×64，6×8 ASCII。刷新 200 ms；没有 OLED 或 I2C 异常不阻塞 CAN，设备每 2 s 重探测。
- CAN 正常模式、自动重传关闭、自动 Bus-off 恢复关闭；软件有限发送期限 100 ms，无 ACK 时计数失败，不能把入邮箱当发送成功。

## 模块与任务

- can_bus：32 帧静态 RX、16 帧静态 TX、16 条发送完成结果队列，标准数据帧/DLC8 校验、ID 过滤、邮箱完成确认和恢复。
- can_upper_protocol：独立 C 协议核心，无 HAL/RTOS 依赖；唯一协议任务拥有状态，周期任务仅发送通知，避免状态竞争。
- can_upper_boot：双页启动计数日志，提交标记最后写入，换页先保留上一页再提交新记录；UID 校验值 XOR 单调计数产生非零 boot ID。
- can_upper_task：协议任务优先级 4、周期任务 3、日志/OLED 1、健康任务 5，全部静态创建。接收中断优先级 5，符合 FreeRTOS ISR API 门限。
- USART1 只有日志任务发送，调用带 100 ms 期限的 HAL_UART_Transmit，不采用全局 printf 字符重定向。高频摘要最多每 ID 每 500 ms 打印一次，上层心跳日志 1 s 限频。日志静态队列满时计 log_drop，关键错误优先替换普通日志，不阻塞通信。

收到 0x180/181/182/183/185/186/187/188 后校验会话、范围和新鲜度。0x184 下层事件与无活动请求对应的 0x120/121 仅记录/拒收，不回虚假执行结果，不进行录制或外设动作。

扩展记录解析并保留能力、机械配置、控制权、健康、停车、左右轴位置、车辆估算里程、同步和通信统计（0x02/10/11/12/13/20/21/22/23/24）。已定义可选记录 0x43/46/50/51/52 做完整性校验后原样记录，不宣称上层拥有相应服务；未登记类型拒收。接收器容量 256 字节，当前已定义记录最长 104 字节。CRC 覆盖起始帧完整 8 字节与精确长度 payload；多字节字段小端。

每方向一个活动记录，允许数据段乱序和同内容重复；同序不同内容、缺段、CRC 错、长度错、提前提交、序号过旧或 200 ms 超时均不覆盖历史快照。半范围序号支持 8/16 位回绕；重复心跳不刷新 500 ms 期限。会话变更/下层重启/Bus-off/RX 溢出清空待发送和旧有效状态。恢复需新邀请、新令牌及三次新心跳，绝不自动运动。当前进程还保留已退役令牌上界，拒绝失联后的旧邀请。

能力分段发送等待每段实际 TX 完成，禁止提交帧超越数据；失败或 200 ms 期限到期后延迟 500 ms 重新发布。Bus-off 采用 100/200/400/1000 ms 上限退避初始化；恢复失败持续记录，不在中断重初始化。

## USART1 与 OLED

帧日志格式：时间、RX/TX、ID、DLC、8 字节数据、LINK、OK/REJECT/TX_DONE/TX_FAILED。TX_DONE 仅表示链路层发送完成，不表示动作执行完成。

记录日志输出 CRC=OK、类型/序号/长度、主要字段和完整 payload；64 位量使用无损十六进制，轴原始计数保留有符号值、标志和源年龄。位置/里程是轮转估算，不能当成绝对轨道定位。

OLED 显示总线状态、RX/TX 完成次数、握手阶段、会话号、最后 ID/帧年龄、下层心跳/轴掩码、速度/轴 RPM、故障和组包错误。速度过期或未知显示 --，无当前可确认故障显示 F:--；BMS 有效位为 0 的串口提示 UNKNOWN/NOT CONNECTED，不伪造 0 V、0% 或正常反馈。

STAT 每秒汇总 RX、实际 TX 完成、TX 错、邮箱忙、RX/TX 丢弃、Bus-off、日志丢弃和 UART 错。全部计数按模 2^32 累加。硬件过滤器外的 ID 不进入软件队列。

PROTOCOL detail 拒绝原因：1 帧格式/处理过迟；2 启动主版本/boot 错；3/4 会话确认不匹配；5 未登记基本 ID；6 会话不匹配；7/8 字段范围/版本错；9 重复或旧心跳；10 不执行下层事件；20～24 邀请/能力上下文错；30～43 记录格式、令牌、序号、完整性、超时或 CRC 错；60 Bus-off；61 RX 溢出。

## 编译与烧录

打开 MDK-ARM/DigitalElectronicseCode.uvprojx，目标 DigitalElectronicseCode，使用 ARM Compiler 5.06。工程指定 upper_sim.sct，不使用旧自动生成的 DigitalElectronicseCode.sct。

应用 Flash 区间 0x08000000～0x0800F7FF（62 KB），最后两页 0x0800F800～0x0800FFFF（2 KB）专供启动计数。采用双页而不是单页，是为了安全轮换和掉电保护。不要在更新固件时擦除这两页；使用“擦除需要的扇区/页”，避免整片擦除。若整片擦除/换 MCU，必须清除双方历史上下文，作为维护操作重新建基线。新 blank 板首次启动自动建立日志；持久化失败、首次记录损坏但没有可信历史、编号耗尽时进入 BOOT_ERR，无固定 ID 降级。

固件输出：MDK-ARM/DigitalElectronicseCode/DigitalElectronicseCode.hex。只烧录 F103，不自动连接或烧录 F4。

CubeMX .ioc 同步 CAN 位时序、中断和 2 KB 堆，但应用仍从 USE_MY_FREERTOS_INIT=1 启动静态任务；重新生成后应核对 main.c 的 TIM2/3/4 禁用、main.h 引用、Keil 源码组和自定义 scatter 文件，避免重新接入电机演示。动态堆缩至 2 KB，为 20 KB SRAM 内的静态队列/任务留出余量。

## 联调验收

1. 不接 F4 上电：串口打印 READONLY、周期公告/心跳发送失败计数；OLED WAIT_BOOT，不能误报 READY。
2. F4 启动顺序任意：0x101/102 → 0x104 → 邀请 0x300/301/302 → 0x105 → 0x106 → 三次递增 0x185 → READY；双方能力记录一致。
3. 注入合法负速度、无效位、未知电池、旧令牌、错误 DLC、重复心跳：验证摘要、--/UNKNOWN 和拒绝计数。
4. 注入缺段、倒序、重复同/异内容、CRC 错、200 ms 超时、记录序号回绕：错误不能更新历史有效记录或新鲜度。
5. 断线、暂停对端心跳、重启任一端、RX 溢出、Bus-off：旧会话清零、重新握手；旧邀请/速度不能恢复动作。
6. 缺 OLED、串口负载过大、对端不 ACK：CAN 周期服务保持运行，丢弃/错误计数可见，健康任务仅在各任务确实运行时喂狗。
7. 抓总线确认从未出现 0x080/110/111，检查最终链接映射不存在 key/tb6612 电机代码；确认保留 Flash 页不包含在 HEX 中。

验证记录：Keil 编译检查、临时目录独立主机协议边界检查和模拟 Flash 检查。主机模拟不替代真实 CAN 物理层、OLED、看门狗及台架断线/Bus-off 测试；尚未连接实物、烧录或验收整车。
