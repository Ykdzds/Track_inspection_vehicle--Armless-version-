# CAN STOP50模拟上层配套操作说明

日期：2026-10-21；启动日志标识 `STOP50-20261021`。仅06低速版修改，05和原始回退工程不动。未自动提交、推送或烧录。

## 按键与运行

| 按键 | 操作 |
|---|---|
| K1短按 | 切换页面 |
| P3长按K1 | 申请授权；准备中取消；已授权时撤权并正常停车 |
| P3短按K2 | 松手消抖后下一档立即应用，无需长按确认 |
| P3长按K2 | 本源正常停车0.40m/s²，禁止同时补一次短按 |
| 全页K3按下 | 消抖后立即全局快速停车0.50m/s²，不要求CAN持权 |

档位为 `0,+100,+200,+300,+400,0,-100,-200,-300,-400`循环，单位电机轴rpm。F407正常加速0.12、减速/目标0/换向0.30m/s²；直接反向由F407完成先降0、反馈确认再反向。未授权/首零期间不积存非零目标，停车后清零并必须重新授权。K3是软件受控停车，不是实体急停或STO。
