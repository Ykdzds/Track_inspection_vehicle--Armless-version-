# F103低速版ERR:101授权失败修复交付说明

日期：2026年10月20日

## 1. 修改边界

- 仅修改本工程 `06_Upper_level_CAN_com_v1.1_low_speed_test`。
- `05_Upper_level_CAN_com_test`、`05_Upper_level_CAN_com_v1.1_readonly`及底盘F407工程保持原样。
- 不修改CAN ID、字节序、CRC、握手、能力位定义、首零流程、目标租期和停车协议。
- 只需重新烧录F103；F407沿用当前已验证固件。

## 2. 修复内容

- `ERR:101`拆分为201～212本地诊断码，OLED和串口可显示具体阻塞原因。
- K1授权先进入固定5秒`AUTH_PREP`准备状态；控制记录和轴反馈仍按原有新鲜度要求检查，不满足时等待新快照，不放宽门禁。
- 能力记录发送完成与F407业务确认分开记录；后续冗余发送失败不覆盖已完成的会话事实，boot/token变化时清除确认。
- 缺少或版本不匹配的0x10配置通过现有0x110查询命令有限重试，最多3次、单次1000ms、总准备期限5秒；查询结果不能完成运动授权。
- 准备期间K3或再次释放取消本地意图，不产生额外停车事务；准备超时、控制源变化、安全锁、故障、非零速度、反馈失效或会话变化均不会自动授权。
- 保留授权成功后的首个新序号零目标、100ms目标刷新、300ms租期、±100rpm限幅和所有失联/停车保护。

## 3. 诊断码

| 代码 | 含义 |
|---:|---|
| 201 | 链路或下层心跳无效 |
| 202 | 本地能力记录尚未完成发送 |
| 203 | F407尚未以新鲜0x11记录确认运动策略 |
| 204 | 控制记录缺失、过期或申请后未刷新 |
| 205 | 控制源占用或生命周期不允许 |
| 206 | 基础门禁不满足 |
| 207 | 安全锁存在 |
| 208 | 左轴反馈不满足 |
| 209 | 右轴反馈不满足 |
| 210 | 底盘配置缺失或版本不匹配 |
| 211 | 底盘配置字段不合法 |
| 212 | 5秒授权准备超时 |
